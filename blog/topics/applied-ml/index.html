Applied Machine Learning

A model that scores well and changes nothing is a failed project. These essays are about applied machine learning where the constraint is rarely the algorithm — it is sparse labels, unstructured text, selection bias, and the gap between a prediction and an action someone can actually take. Topics include K-means segmentation rescued by principal component analysis, churn prediction paired with LDA topic modeling of call-center notes, and the honest engineering required when under two percent of your population has a usable label.
